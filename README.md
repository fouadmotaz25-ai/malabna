# NextMove

منصة رياضية عراقية للحجز والتدريب والمتاجر والتغذية ومجتمع اللاعبين. تعمل كتطبيق ويب قابل للتثبيت، ويستخدم النظام Supabase للمصادقة وقاعدة البيانات والتخزين والوظائف الخلفية.

## التشغيل والتحقق

```bash
npm install
npm run dev
npm test
npm run lint
```

## مكونات النسخة الرسمية

- تسجيل دخول بالبريد أو رقم الهاتف عبر رمز مؤقت، مع GitHub OAuth.
- صلاحيات منفصلة للمستخدم والتاجر والمطعم وصاحب الملعب والجيم والمدرب.
- حجز مواعيد الملاعب ومنع الحجز المزدوج وإشعارات المالك.
- عربون الحجز النقدي مضبوط على 5,000 د.ع، ولا يتأكد قبل إشعار موثوق من بوابة الدفع.
- تقسيم قيمة الحجز على اللاعبين وسجلات منفصلة للحصص.
- نشر منتجات ووجبات وبرامج تدريب ومحادثات خاصة بعد الاشتراك.
- تقييمات مباريات ومقاطع رياضية وترتيب شهري.
- سياسات وصول RLS وتخزين مقيد حسب المالك.
- تطبيق PWA متجاوب يعمل على الهاتف والحاسوب.

## الجزء المتبقي

يلزم إدخال بيانات مزود الدفع التجاري ثم ربط بدء الدفع وويب هوك التحقق النهائي. لا تُحفظ أرقام البطاقات داخل NextMove، ولا تُعتبر أي عملية مدفوعة ناجحة إلا بعد تحقق الخادم من مزود الدفع.
